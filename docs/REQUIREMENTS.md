# zk-viewer-vscode 需求说明

## 1. 项目概述

### 1.1 背景

Apache ZooKeeper 是分布式系统中广泛使用的协调服务，但日常运维和调试缺乏方便的图形化工具：

- 命令行工具 `zkCli.sh` 功能完整但使用不便，不适合快速浏览和编辑；
- 独立 Web 工具（如 zkui、ZooInspector）需要额外部署，与开发环境割裂；
- 开发人员希望在熟悉的 VS Code 内直接完成 ZooKeeper 的浏览、查询和节点操作。

### 1.2 目标

开发一个 VS Code 插件 `zk-viewer-vscode`，提供轻量级、可视化的 ZooKeeper 客户端，支持：

- 节点树可视化浏览；
- 节点路径定位与全树搜索；
- 节点数据的 JSON 格式化展示与编辑；
- 节点的新增、修改、删除。

### 1.3 目标用户

- 后端与中间件开发人员：调试配置节点、查看服务注册信息；
- 运维与 SRE：检查集群状态、快速修改配置节点。

### 1.4 非目标

- 不实现 ZooKeeper 管理面功能（如四字命令、集群重配置）；
- 不做完整的 ACL 管理界面（仅支持基本的 digest 认证与节点 ACL 查看）。

## 2. 功能需求

### 2.1 连接管理

- 支持保存多个连接配置：连接名称、地址（`host:port`）、chroot 路径、会话超时时间；
- 支持连接 / 断开操作，断开后自动释放会话；
- 支持断线自动重连与友好的错误提示；
- 支持 digest 认证（用户名 / 密码），凭据通过 VS Code `SecretStorage` 加密保存；
- 在侧边栏显示连接状态（已连接 / 已断开 / 连接中）；
- 侧边栏标题栏提供 **加号（＋）快捷入口**，一键新建连接；连接 / 断开按钮随连接状态自动切换显示。

### 2.2 节点树可视化

- 侧边栏以树形结构展示 znode 层级；
- 子节点懒加载，点击展开时才请求，避免大数据量卡顿；
- 节点图标区分节点类型（持久 / 持久顺序 / 临时 / 临时顺序）；
- 子节点支持多种排序方式（配置项 `zkViewer.treeSort` 或侧边栏菜单「Sort Nodes...」）：
  - 按名称升序 / 降序（默认名称升序）；
  - 按创建时间（`ctime`）升序 / 降序；
  - 按更新时间（`mtime`）升序 / 降序；
  - 保持服务器顺序；
- 活动栏图标采用 **节点树造型**，与「ZooKeeper 可视化」定位一致；
- 节点旁展示关键信息，如数据大小、子节点数量；
- 右键菜单提供刷新、新增、编辑、删除、复制路径、导出当前节点数据和导出完整子树数据等节点级操作；
- 导入是全局操作，不放入节点右键菜单；`ZooKeeper Nodes` 视图标题栏的省略号菜单应在节点排序下方提供导入入口；
- 标题栏菜单提供只读的导入格式说明与标准模板下载入口；格式示例不允许编辑。

### 2.3 查询与搜索

- **路径定位**：输入完整路径（如 `/app/config`）直接跳转并展开目标节点；
- 搜索提供**精确路径模式**：输入完整路径直接命中并定位到该节点（等价于路径定位，统一从搜索入口使用）；
- 侧边栏标题栏提供 **放大镜（搜索）快捷入口**，点击后弹出搜索模式与关键字输入；
- **名称搜索**：按节点名称搜索全树，支持前缀、通配符与正则匹配；
- **内容搜索**（可选增强）：搜索节点数据中包含指定文本的节点，支持限定子树范围；
- 搜索结果以列表展示，点击可跳转到对应节点。
- **性能**：遍历采用层级并行 + 批量限流，耗时随树的深度而非节点数量增长；内容搜索预先读取 stat，跳过空数据与超大节点（超过 `zkViewer.maxNodeDataBytes` 不参与匹配），避免无谓的数据下载。
- **结果完整性（优先）**：内容搜索默认不过滤节点大小（`zkViewer.maxNodeDataBytes` 为 0），搜索默认最多遍历 `500000` 个节点（`zkViewer.maxSearchNodes`），也可设 0 表示无限制；达到上限时界面明确提示结果可能不完整。
- **子树搜索**：树节点右键「Search in this subtree...」以当前路径为根进行搜索，遍历范围小、速度快且结果完整。
- **搜索反馈**：搜索过程显示进度并可取消（Esc）；被跳过的超大节点数量会提示用户。

### 2.4 JSON 查看与编辑

- 双击节点打开详情面板（Webview），展示节点数据与 stat 信息（`cZxid`、`mZxid`、`version`、`dataLength`、`numChildren`、`mtime` 等）；
- 节点数据若为合法 JSON，以格式化（缩进、语法高亮）方式展示；
- 支持 JSON（默认）/ TXT 显示模式与自动换行开关；JSON 格式化只作用于展示层，不改变原始数据；
- 支持一键紧凑化合法 JSON，移除结构空白但保留字符串内容中的空格与换行；
- 非 JSON 或二进制数据降级为文本 / 十六进制视图，并明确提示；
- 支持 JSON 编辑：**默认只读**，点击「编辑」按钮后才进入编辑模式，避免误触修改；保存时使用 `setData` 原子写入；
- 编辑期间监测节点变化：节点被其他端删除时立即弹出错误提示并自动关闭详情面板，树视图同步刷新；保存前校验节点存在，保存失败（节点已删除 / 版本冲突等）弹出 VS Code 错误通知；
- 大节点数据支持分页或按需加载，避免一次加载过大内容。

### 2.5 节点操作

- **新增节点**：选择节点类型（持久 / 持久顺序 / 临时 / 临时顺序），填写节点名与数据（可选）；
- **编辑节点**：修改节点数据并保存，保存前展示版本信息（乐观锁提示）；
- **删除节点**：支持单个删除与递归删除，删除前二次确认并提示影响范围；
- **刷新**：刷新当前节点及子节点，同步外部变更。
- **导出节点**：支持导出当前节点，或当前节点及所有后代节点；结果包含每个节点的完整路径与无损数据，非 UTF-8 数据使用 Base64。
- **导入节点**：读取导出 JSON，严格校验 `zk-viewer-node-data` 版本 1、固定字段、路径与编码后按父级优先恢复节点；已存在节点可选择覆盖或跳过，创建节点使用持久模式。未知字段、自定义映射或其他 JSON 结构不得导入。
- **格式模板**：只读示例与下载文件必须和真实导出共用数据类型与序列化实现，确保导出文件可以直接导入。

### 2.6 其他

- 操作日志面板记录连接、增删改、保存等关键操作与错误；
- 命令面板支持全部核心操作（`zkViewer.connect`、`zkViewer.search`、`zkViewer.refresh` 等）；
- 标题栏提供语言按钮，可选择跟随 VS Code、中文或英文并全局持久化；导入、导出、模板及语言相关命令按钮和交互提示应立即切换。

## 3. 非功能需求

- **性能**：单连接下 500+ 子节点树浏览不卡顿；数据加载采用懒加载与分片；
- **安全**：连接凭据加密存储，不写入日志；支持 TLS 连接 ZooKeeper；
- **可靠性**：会话超时、网络抖动有明确提示与重连机制，不产生僵尸会话；
- **兼容性**：VS Code `>= 1.60`（凭据存储依赖 `SecretStorage`，其 API 门槛为 1.57）；ZooKeeper `3.4+`；支持 Windows / macOS / Linux；
- **可维护性**：TypeScript 编写，模块化组织，提供单元测试与集成测试。

## 4. 技术方案（建议）

| 模块 | 方案 |
| --- | --- |
| 语言 / 运行时 | TypeScript + Node.js |
| 扩展界面 | TreeDataProvider（节点树）、Webview（详情 / 编辑面板） |
| ZooKeeper 客户端 | `node-zookeeper-client`（优先评估维护状态，必要时替换） |
| 凭据存储 | VS Code `SecretStorage` |
| 测试 | Mocha + `@vscode/test-electron`，客户端逻辑以 mock 隔离 |
| 打包发布 | `vsce` 生成 `.vsix`，发布至 VS Code Marketplace |

## 5. 目录结构（建议）

```text
src/
  extension.ts          # 激活入口
  connections/          # 连接管理与配置
  tree/                 # 节点树视图
  search/               # 路径定位与搜索
  webview/              # 详情 / 编辑面板
  zk/                   # ZooKeeper 客户端封装
media/                  # Webview 静态资源
test/                   # 集成测试
```

## 6. 验收标准

- 能保存并连接多个 ZooKeeper 地址，连接状态正确展示；
- 能浏览节点树并懒加载子节点；
- 能按路径定位、按名称 / 内容搜索节点并跳转；
- JSON 数据正确格式化展示，编辑后保存生效且数据一致；
- 新增、编辑、删除操作均生效，删除有确认；
- 单节点 / 子树导出后可通过同一生产解析与导入链路恢复，UTF-8 与二进制数据均保持一致；
- 标准模板为只读且下载内容可由生产导入器解析；未知字段和非标准格式在写入前被拒绝；
- 断开连接后重连正常，错误有明确提示。

## 7. 里程碑规划

- **M1 基础浏览**：连接管理 + 节点树 + 节点详情（stat / 数据展示）；
- **M2 增删改**：JSON 编辑、新增节点、删除节点（含递归）；
- **M3 查询搜索**：路径定位 + 名称搜索 + 内容搜索；
- **M4 完善发布**：认证 / TLS、性能优化、错误处理、文档与 `.vsix` 打包。

## 8. 风险与注意事项

- **大数据量**：超大节点树或大节点数据可能影响 UI，必须懒加载与分片；
- **二进制数据**：ZooKeeper 数据不保证是文本，需提供非 JSON 降级视图；
- **会话管理**：临时节点与会话绑定，断线后临时节点消失，需有明确提示；
- **依赖风险**：ZooKeeper 客户端库维护情况需在 M1 前评估确认。
